# 😀 Emoji Translator

A fun and simple web application that converts common words into emojis.

Type a sentence, click the **Translate** button, and the app automatically replaces supported words with matching emojis.

## 🚀 Features

- Convert words into emojis
- Simple and clean user interface
- Copy translated result
- Clear button
- Supports multiple categories of emojis
- Works directly in the browser
- No backend required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 How to Use

1. Open `index.html` in your browser.
2. Type a sentence in the text box.
3. Click **Translate**.
4. The supported words will be replaced with emojis.
5. Click **Copy Result** to copy the translated text.

## 💡 Example

### Input

I love pizza and coffee. My dog is happy.

### Output

I ❤️ 🍕 and ☕. My 🐶 is 😊.
